# 虚拟风洞(WebGPU · LBM)

给造型部门用的网页版实时风洞:格子玻尔兹曼求解器跑在显卡上,车身模型体素化为障碍物,
车头前一排喷嘴放出烟线,车身表面按压力系数着色,实时读出阻力系数 Cd。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端里给出的地址(默认 http://localhost:5173)。
**需要支持 WebGPU 的浏览器**(Chrome / Edge 113+,独显最佳;需要显卡支持 ≥180MB 的
storage buffer 绑定,主流独显都满足,不满足时程序会自动降档网格规模)。

## 功能对照

| 需求 | 实现 |
| --- | --- |
| ≥200 万格子,≥20 步/秒 | 默认 256×96×96 ≈ 236 万格子,D3Q19;左上角实时显示"步/秒"(独显通常数百) |
| 车身表面压力着色 | 每个网格顶点沿法向采样密度场 → 压力系数 Cp → 蓝(低压)→红(高压)顶点色 |
| 阻力系数 / 方案对比 | 动量交换法在 GPU 上在线积分气动力 → Cd / Cl;「记为方案 A/B」后自动算 ΔCd |
| 烟线 | 2048 粒子 × 48 点历史,RK2 沿流场平流,半透明细丝(line-list)渲染,车尾可见卷涡 |
| 改造型不重算 | 重新体素化只更新障碍物掩码,流场状态保留;新露出的格子单独置平衡态,流场接着算 |

## 操作

- **左键**旋转 · **右键**平移 · **滚轮**缩放
- 右侧面板:风速、粘度、烟线/中截面云图开关
- 内置参数化车型:**后视镜位置、尾翼角度、尾翼开关、离地间隙**——拖动滑杆,
  150ms 防抖后自动重新体素化,流场不中断,可以直接看 Cd 往哪边动
- 「导入 GLB / STL…」加载自己的模型(自动归一化到 4.4m 车长、最长轴对齐 x、底面贴地;
  车头方向不对就点「模型掉头 180°」)
- 改完造型点「记为方案 A」,再改、点「记为方案 B」,左下角直接给出 ΔCd 和百分比

## 技术要点

- **求解器**:D3Q19,BGK 碰撞 + Smagorinsky 亚格子应力(高 Re 下稳定),push 式
  碰撞-迁移融合 kernel,单缓冲双份 ping-pong
- **边界**:左侧平衡态入口、右侧零梯度出口、四壁自由滑移(镜面反射);车身为反弹边界
- **测力**:反弹链接上的动量交换,定点原子累加,每帧读回平均
- **体素化**:三角面片与格子做 SAT 重叠测试标记表面,再从域边界洪泛填充外部,
  剩余即内部固体;同时统计正面投影面积作为 Cd 参考面积
- **Cd 口径**:`Cd = Fx / (½·ρ·U²·A)`,格子单位,ρ=1;用于同网格同风速下的相对比较

## 已知限制(相对比较够用,绝对值别当真)

- 四壁(含地面)是自由滑移壁面,没有移动地面和边界层,阻塞率约 12%(车宽/域宽)
- 出口是简单零梯度,尾迹长到出口附近会有少量反射
- Cd 的绝对值受网格分辨率限制,但**两个方案之间的差值**在同一设置下是有意义的
- 导入模型只取三角面片位置与索引(GLB 支持节点变换,不支持材质/蒙皮/ Draco 压缩)

## 文件结构

```
src/
  main.ts       主循环、交互编排
  lbm.ts        LBM 求解器(WGSL compute kernel 全在这里)
  particles.ts  烟线粒子(平流 + 细丝渲染)
  render.ts     地面 / 速度云图切片 / 车身压力着色
  carmesh.ts    参数化车型 + GLB/STL 解析
  voxelize.ts   三角网格 → 障碍物掩码
  camera.ts     轨道相机
  gpu.ts        设备初始化(申请大 storage 限额)
  ui.ts         控制面板
```
