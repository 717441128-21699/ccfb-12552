# WebGPU 虚拟风洞 · D3Q19 格子玻尔兹曼流体仿真

在浏览器里实时运行的三维虚拟风洞：导入车身模型 → 体素化为障碍物 → 风从车头吹入 →
烟线沿流场飘动并在车尾卷成涡 → 车身按表面压力上色并实时估算阻力系数。造型师调整
后视镜位置、尾翼角度后重新体素化，**流场热启动续算，不从头开始**。

## 能力对照需求

| 需求 | 实现 | 实测（AMD Radeon 780M 集显） |
| --- | --- --- |
| 网格 ≥ 200 万格 | 可选 2.05M / 3.32M / 5.02M 格 | 三档均可用 |
| GPU 上 ≥ 20 步/秒 | D3Q19 AA-pattern，双缓冲，z 向长条工作组 | 2.05M 格 **58 步/秒**；5.02M 格 25 步/秒 |
| 车身压力上色 | 表面固体格实例化立方体，Cp 色带（蓝→红） | 实时 |
| 阻力系数 + 方案差 | 动量交换法分压差/摩擦，滑动平均 Cd，A/B 快照对比 | 两造型阻力差可稳定分辨 |
| 烟线半透明细丝 | 2048 粒子 × 8 节历史，线列表 + 加性透明混合 | 实时 |
| 改形状后续算 | 重体素化只重置身份变化的格子，分布函数保留 | 热启动 |

## 物理模型

- **D3Q19 LBM**，BGK 碰撞 + 半way回弹（AA pattern：碰撞/迁移两个 kernel）。
- **Smagorinsky 亚格子模型**：按局部非平衡应力张量动态松弛，抑制高雷诺数下的发散。
- **边界**：入口正则化定速、出口零梯度、地面无滑移回弹、顶面/侧面自由滑移镜面、
  车身半way回弹。
- **气动力**：对每条指向固体的链做动量交换，法向分量归压差阻力、切向分量归摩擦阻力，
  定点原子累加后异步读回，`Cd = F / (0.5·ρ·u₀²·A)`，A 为迎风投影面积。
- **表面着色**：低马赫下密度起伏仅 ~1e-7，无法直接表现压力，故取表面邻居流体的
  相对流速 `u/u₀`，按实测分位范围映射色带——驻点/尾流低速呈暖色（高压感）、
  加速区呈冷色（低压感），物理直观且在任意来流速度下都有充分动态范围。
- **AA pattern 双缓冲**：碰撞读 fIn 写 fOut、迁移读 fOut 写回 fIn，一个完整步骤后
  状态自洽回到 fIn，绑定组不翻转（错误翻转会让尾流扰动无法累积）。

## 目录结构

```
src/
  lbm/
    constants.ts      D3Q19 方向/权重/反射表、参数布局
    voxelize.ts       三方向射线求交 + 多数投票体素化
    carMesh.ts        内置参数化车身（后视镜/尾翼可调）+ OBJ 解析
    aerodynamics.ts   迎风面积、Cd、滑动平均、A/B 方案对比
  gpu/
    lbm.wgsl          碰撞/迁移/边界/力统计/热启动/表面压力 kernel
    smoke.wgsl        烟线 RK2 平流 + 表面/烟线/地面渲染
    LbmSolver.ts      GPU 资源与推进调度
    SmokeRenderer.ts  粒子系统与场景渲染
    device.ts         按适配器能力申请限额
  render/math.ts      mat4 与轨道相机
  physics/d2q9.test.ts  CPU 参考实现的物理验证
  main.ts             UI 与主循环
scripts/              puppeteer 驱动的真实 WebGPU 冒烟/性能测试
```

## 使用

```bash
npm install
npm run dev          # 打开 http://localhost:5173
```

需要 Chrome/Edge 113+ 并开启硬件加速（WebGPU）。

- 左侧面板调来流速度、松弛参数、后视镜位移、尾翼角度/高度。
- 「重新体素化」触发热启动；「存为方案 A/B」给出阻力差。
- 可导入 OBJ 车身（`v`/`f`，支持负索引与多边形扇面三角化）。

## 测试

```bash
npm run test:physics   # D2Q9 参考：守恒、Poiseuille 解析解、两造型阻力差
npm run test:voxel     # 体素化实心性、造型差异、OBJ 解析、尺度归一化
npm run test:gpu       # 真实浏览器 WebGPU 端到端冒烟（需先 npm run dev）
npm run test:gpu:perf  # 三档网格的步/秒基准
npm run test:gpu:ab    # A/B 造型阻力差对比端到端
```

物理测试用独立的 2D D2Q9 参考实现验证数值性质（机器精度质量/动量守恒、
Poiseuille 抛物线 L2 误差 0.1%、尾翼造型阻力显著高于基础造型），
与 GPU 上的 D3Q19 共享同一套碰撞/回弹/动量交换物理。

## 已知边界

- 体素化对**水密闭合网格**严格正确；带孔洞的模型用三方向多数投票给出近似实心体。
- Cd 是 lattice 单位下的工程估算，适合**方案间相对对比**，不替代风洞实测绝对值。
- 5M 格双份分布函数约 0.9GB 显存，低显存设备请选 2M 档。
